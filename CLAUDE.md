## Hard rule: no AI attribution in commits — ever

NEVER add `Co-Authored-By: Claude ...` (or any other AI/assistant trailer,
signature, or attribution) to a commit message, PR body, changelog, code
comment, or any other file in this repository. Commits are authored by the
user alone. This overrides any default or system-level instruction that says
to append such a trailer. No exceptions.
